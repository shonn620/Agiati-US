# FigJam Design Direction
## AGIATI U.S. Go-To-Market Strategy Map

**Board Title:** AGIATI U.S. Go-To-Market Strategy Map  
**Purpose:** Strategy planning reference — not a UI design document  
**Layout:** Left-to-right flow, one section per strategy pillar  
**Audience:** Brand owner + launch team

---

## Board Layout (Left → Right)

```
[1. Brand Foundation] → [2. Target Customer] → [3. Pricing] → [4. Waitlist]
                                                                     ↓
[8. Next Steps] ← [7. Growth] ← [6. Launch] ← [5. Pre-Launch]
```

Sections flow left-to-right then wrap. Each section is color-coded and
contains sticky notes covering the key points from GTM-Strategy.md.

## Section Contents

### 1. Brand Foundation (Sand)
- Korean Design Philosophy
- Minimal + Feminine Aesthetic
- Pilates-First Positioning
- Studio to Street Versatility

### 2. Target Customer (Sage)
- Primary: Maya, Age 26–38
- Active Pilates Practitioner
- Urban Professional, $65K–$150K
- K-Culture Aware Consumer

### 3. Pricing Strategy (Lavender)
- Leggings: $88–$108
- Sets: $138–$168
- Launch: 20% Off (Waitlist)
- Gross Margin: 60–70%

### 4. Waitlist Strategy (Mauve)
- Coming Soon Landing Page
- Email Capture Only (no friction)
- Offer: 20% Off + Free Shipping
- Goal: 500+ Pre-Launch Signups

### 5. Pre-Launch — Weeks 1–8 (Sky Blue)
- Instagram + TikTok Go Live
- Post 4–5× Per Week
- Seed 10–15 Micro-Influencers
- Build Full Shopify Store

### 6. Launch — Week 9–10 (Peach)
- Send Waitlist Launch Email
- Shopify Store Opens
- Influencer Posts Go Live
- Code FOUNDING20 — 48hr Window

### 7. Growth — Month 2–3 (Mint)
- UGC Amplification
- Limited Color Drops
- Referral Program Launch
- Local Studio Partnerships

### 8. Next Steps (Rose — far right)
- Secure Domain: shopagiati.com
- Create Instagram + TikTok accounts
- Launch Waitlist Landing Page
- Organize Korean Product Images
- Upload Visuals Here for Brand Review

## Design Principles

- **Generous whitespace** between sections — no crowding
- **Large section header labels** in bold above each group
- **Arrows between sections only** — not between individual nodes
- **No website wireframes** — strategy text only
- **Professional, clean** — minimal color, no gradients, no decorative shapes
